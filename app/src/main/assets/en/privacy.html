This app [Mix Calculator] is a purely offline, standalone tool. It requires no internet connection.
This app solemnly declares: it does not collect, read, upload, store, or share any user privacy data.

1. No privacy collection
This app does not access phone number, device information, location, photo album, microphone, contacts, account information, or any other user privacy.

2. Fully offline operation
This app performs no network requests, no background networking, no ads, no updates, and no log uploads. It runs entirely locally.

3. No third-party SDKs
This app integrates no analytics, advertising, push, crash-reporting, or other third-party tools. There is no third-party data acquisition.

4. All user data is stored locally
The shed numbers, feed ratios, feed-change data, and other content you enter are saved only in the app's local private space, and are never uploaded to the cloud or disclosed externally. This data resides in the app's private directory, which users cannot access through an external file manager. Uninstalling the app deletes all this data.

5. User rights
Users can view and delete entered data within the app; raw files in the app's private directory cannot be accessed through the system file manager. Uninstalling the app clears all app data.

6. Policy updates
If later versions are released, the privacy policy will be updated accordingly, with the latest page prevailing.
