# 秒算虾料 0.3.7 升级说明

**适用版本**：安卓版 0.3.7（versionCode 10）。
**安装方式**：直接覆盖安装，数据保留（与 0.3.6 签名一致）。
**安装包**：`秒算虾料-0.3.7-release.apk` — 12,748,508 字节
SHA256 `E64D7DE8F5584D21F179A8F0DCEB0B2D5DAD994381E1BFBB17AC4106C3C881EE`

## 这次改了什么

### 录入
- **「下一步」逐格跟进**：键盘上的「下一步」沿本行可填格一格格往后走，格子被挤出屏幕时表格自动滚过去，
  输入框始终在可视区内，不会出现「按了没反应、其实是在屏幕外」。
- **本行填完跳下一行**：本行最后一个可填格填完再按「下一步」，直接落到下一行的棚号。
- **「下一行 ▾」修好**：下一行这一格不能填时，自动落到下一行第一个能填的格，不再原地不动。
- **防连点**：连续快速点「下一步」不会重复跳格、重复结算。

### 棚号
- **列更宽、字更大且固定**：棚号列 64dp，铺满档 15dp 字号（手机滚动档 14dp），不随系统「字体大小」变化。
- **一行最多 99 个**：超出即时提示，超出部分不计入棚数与料量；改回合法值后自动接着算。

### 界面
- **「重置」钉在右下角**：表格左右上下滚动都在原位，点它仍先弹确认框。
- **表格自绘重构**：底色、格子、居中文字、冻结线拆成独立绘制部件（纯搬移，行为不变）。

### 大屏与屏幕方向
- **宽窗口 11 列按比例撑满**：窗口 ≥600dp（平板竖屏、大屏分屏）时，11 列按原比例整体缩放，
  总宽严格等于窗宽，右侧不留白、也没有横向滚动缝。手机档仍是固定 604dp + 横向滚动。
- **固定竖屏**：清单里锁 `portrait`，系统在建启动窗口之前就按竖屏建，
  横着拿设备点开也不会「先横一下再转回来」。
- **窗口宽度变了才重算**：分屏、折叠展开、拖窗口大小时，等根布局拿到新宽度再重算列宽并重搭表格，
  不在 `onConfigurationChanged` 里算（那一刻根布局还是旧宽度，会把表压窄）。

## 已知事项
- **分屏比 600dp 略窄时仍是手机布局**：例如小米 Pad 5 分屏窗口约 570dp，11 列看得到 10 列多一点，
  第 11 列要左右滑一下。这是有意保留的：再把列压窄，棚号列 15dp 字号的两行文本会被裁切（棚号列不补省略号），
  比分屏多滑一下更难接受。
- **Android 16 及以上系统会忽略大屏方向锁定**：系统对 ≥600dp 窗口强推自适应布局，
  这类平板上应用仍可能横过来（不是缺陷，横屏时 11 列同样铺满）。
- 若设备上装的是其它密钥签名的包，需要先卸载（会清数据）。
