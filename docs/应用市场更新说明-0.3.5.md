# 秒算虾料 0.3.5 应用市场更新说明

> 适用版本：Android 0.3.5（versionCode 8）
> 对比版本：0.3.4
> 用途：应用市场“版本更新说明/更新日志”可直接复制下方文案。

## 一、短版（约 60 字，适合更新弹窗）

修复折叠屏外屏挤成 11 列、快捷设置面板不铺满、表头弹窗往右溢出等问题，折叠、分屏、平板都能正常显示。

## 二、标准版（约 180 字，适合应用市场更新说明）

这次主要修显示问题，尤其是折叠屏和大屏设备：

1. 修复折叠屏手机折叠成外屏后仍显示 11 列、每列被挤得很窄的问题；现在会按窗口宽度自动切换布局，外屏用手机布局（可左右滑动），展开后用大屏布局。
2. 快捷设置（列管理）面板改为左右铺满当前窗口，不再固定宽度、右侧留白；折叠、展开、分屏、转屏后都会跟着窗口重新适配。
3. 表格已经铺满 11 列时，菜单不再显示「快捷设置」；只要还有列被隐藏，入口一定保留，随时能恢复。
4. 修复表头弹窗（水比 / 发酵料 / 列操作）在靠右列往右溢出屏幕的问题，现在弹窗右边缘会对齐被点的单元格，并自动收进屏幕内。
5. 平板上手动隐藏的列不再被强制恢复。

升级不会清空已保存的数据；首次打开新版本时，可能需要重新确认隐私政策与用户协议。

## 三、详细版（适合应用商店“更新内容”长文本）

本次 0.3.5 版本集中修复不同屏幕形态下的显示问题：

- **折叠屏外屏不再挤成 11 列**：之前判断“是不是平板”用的是设备类型，折叠屏即使折叠成外屏（约 370dp）也会被当成平板，把 11 列硬压进窄屏。现在改为按**当前窗口宽度**判断（600dp 起算大屏布局），外屏自动切回手机布局，固定列宽 + 左右滑动，字不再被压扁。
- **快捷设置面板铺满窗口**：列管理面板去掉了固定的 360dp 宽度上限，改为左右铺满当前窗口；折叠、展开、分屏、转屏后都会按新窗口重新计算，不再出现右侧留白。
- **「快捷设置」入口更合理**：表格已经铺满 11 列、没有列需要隐藏时，菜单不再显示「快捷设置」；但只要还有列被隐藏，入口一定保留，不会出现“藏了列却找不回入口”的情况。
- **表头弹窗不再往右溢出**：水比、发酵料、列操作三个弹窗改为右边缘对齐被点的单元格，靠左/靠右都会自动收进屏幕内，点完能直接选。
- **平板隐藏列生效**：平板上手动隐藏的列不再被强制恢复，隐藏列这条退路在窄窗口下也能用。
- **窗口变化时菜单自动关闭**：折叠、展开、分屏切换时，已打开的主菜单和快捷设置会直接关闭，不会停留在旧宽度、旧状态。

升级不会清空已保存的数据。首次打开新版本时，可能需要重新确认隐私政策与用户协议；建议升级前把重要数据截图或抄录一份。
