# 秒算虾料 0.3.6 升级说明

**适用版本**：安卓版 0.3.6（versionCode 9）；鸿蒙版同步 0.3.6（内部验证用，不对外分发）。
**安装方式**：直接覆盖安装，数据保留（与旧版签名一致）。

## 这次改了什么

### 计算
- **所有行平等**：取消「第一行 / 第一个单元格 = 总棚数」，每行棚数 = 本行棚号在「后行优先」覆盖后实际占有的个数，不会出现负数或被首行扣光。
- **改棚号 = 改棚数**：棚数变化时每棚平均保持不变，料量按「平均 × 新棚数」重算；其它行覆盖导致的棚数变化同样处理。
- **声明与显示分开**：落盘存你填的原文，显示用覆盖后实际拥有的号。第 1 行 `1-40`、第 2 行 `1-15` 时第 1 行显示 `16-40`；第 2 行改小/清空，被占走的号会自动退回。以前号被占走就永久消失。
- **每敲一个字符全表重算**：用进入编辑前的快照重推，半成品区间（`16-40` 打到一半的 `16-4`）不会永久抢走别人的号；正在编辑的行始终显示原文。

### 棚号气泡
- 点号码选中（绿→蓝），⋮ 菜单：全选 / 反选 / 删除 / 转出；另一行气泡里多出「转入」。
- 转出只记进内存待转池，来源行不动；点别处、切批次、转屏、退到后台立刻作废。
- 转入按号码集合换主人，两行文本重排成实际拥有的号；整行转给空行会被拦下。
- 删除只动本行声明：上面有行填过 → 退回那行继续算料；没有来路 → 真删除。确认框会点名列出真删的号。

### 行回收
- 填过内容但有效棚数为 0 的行，在换格收起、切批次、退出、载入时整行销毁，下面行上顶、底部补空行；一次结算全部删完，不会一行一行往上进。编辑途中只置灰、不动数据。

### 界面
- 表格字号加大并固定：表体/表尾 16sp、表头 14sp，不再跟随系统「字体大小」变化。
- 棚号列字号固定 16dp（不乘系数、不随内容自适应、不跟随系统字体），列宽 72dp，两行折叠结果不裁边。
- 棚号格两行极简显示：每行 ≤ 9 字符、最多两行，连续区间不切断，省略号只由折叠算法产生。
- 点「棚数」弹出的棚号气泡：左边缘对齐棚数格，高度最多到表尾行上沿，超出在弹窗内滚动；字号有上限。
- 帮助页去掉「首行」说法：任意行都可以自由填写棚号。

### 安装包
- 安卓 APK 同时启用 V1 + V2 + V3 三种签名方案。

## 已知事项
- 与 0.3.5 及更早版本签名一致，可直接覆盖安装；若设备上装的是其它密钥签的包，需要先卸载（会清数据）。
- 鸿蒙版与安卓版计算规则一致；鸿蒙 HAP 因签名/设备限制不对外分发。
