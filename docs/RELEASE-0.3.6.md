# 秒算虾料 0.3.6 升级说明

**适用版本**：安卓版 0.3.6（versionCode 9）；鸿蒙版同步 0.3.6（内部验证用，不对外分发）。
**安装方式**：直接覆盖安装，数据保留（与旧版签名一致）。

## 这次改了什么

### 计算
- **所有行平等**：取消「第一行 / 第一个单元格 = 总棚数」，每行棚数 = 本行棚号在「后行优先」覆盖后实际占有的个数，不会出现负数或被首行扣光。
- **改棚号 = 改棚数**：棚数变化时每棚平均保持不变，料量按「平均 × 新棚数」重算；其它行覆盖导致的棚数变化同样处理。

### 界面
- 表格字号加大并固定：表体/表尾 16sp、表头 14sp，不再跟随系统「字体大小」变化。
- 棚号列字号固定、不再自动缩小，放不下自动换行（最多两行、居中）。
- 点「棚数」弹出的棚号气泡：高度最多到表尾行上沿，超出在弹窗内滚动；字号有上限。
- 帮助页去掉「首行」说法：任意行都可以自由填写棚号。

### 安装包
- 安卓 APK 同时启用 V1 + V2 + V3 三种签名方案。

## 已知事项
- 与 0.3.5 及更早版本签名一致，可直接覆盖安装；若设备上装的是其它密钥签的包，需要先卸载（会清数据）。
- 鸿蒙版与安卓版计算规则一致；鸿蒙 HAP 因签名/设备限制不对外分发。
