# 秒算虾料 0.3.7 应用市场更新说明（安卓端）

> 用途：应用市场「版本更新内容 / 更新日志」输入框，直接复制下面代码块里的纯文本。
> 简单版给市场默认展示用，详细版留给要求「详细更新内容」的市场。
> 本版没有改计算规则，只是录入手感、界面位置和大屏显示的问题修复，数据全部保留。

---

## 一、简单版（约 255 字，推荐直接用这版）

```
0.3.7 更新：录入更顺手

1. 键盘上的「下一步」会沿本行一格一格往后走；格子跑出屏幕时表格自动滚过去，输入框始终看得见。
2. 本行最后一个可填格填完，再按「下一步」直接跳到下一行的棚号；「下一行 ▾」遇到下一行这格不能填时，也会落到下一行第一个能填的格。
3. 「重置」按钮固定在右下角，表格左右上下怎么滚都在原位，随时点得到。
4. 棚号列加宽、字号加大并固定，不随手机字体大小变化；一行棚号最多 99 个，超出即时提示。
5. 平板等大屏上 11 列自动撑满屏宽，不用再左右滑；应用固定竖屏，横着拿设备点开也不会先横一下再转回来。
```

## 二、详细版（约 465 字）

```
0.3.7 更新说明

【录入更快】
· 键盘上的「下一步」沿本行可填格一格格往后走，格子被挤出屏幕时表格自动滚过去，输入框始终看得见。
· 本行最后一格填完再按「下一步」，直接跳到下一行的棚号，不用来回点。
· 「下一行 ▾」修好了：下一行这一格不能填时，自动落到下一行第一个能填的格。
· 连续快速点「下一步」不会重复跳格、重复结算。

【棚号看得更清楚】
· 棚号列加宽，字号加大并固定，不跟随系统「字体大小」变化。
· 手机档一行 7 字、最多两行；平板竖屏一行 9 字，「1-40」这类区号不会从中间切断。
· 一行棚号最多 99 个：超出会提示、不计入棚数与料量；改回合法值自动接着算。

【大屏与竖屏】
· 平板等大屏上 11 列按原比例撑满屏宽，右侧不留白、也没有横向滚动缝。
· 应用固定竖屏：横着拿设备点开也不会先横屏闪一下再转正；平板同样竖屏，11 列照样铺满。
· 分屏这类更窄的窗口仍按手机布局，第 11 列左右滑一下就到。

【「重置」随时点得到】
· 右下角「重置」固定在原位，左右上下滚动都不影响，点它仍先弹确认框。

· 升级不清空已保存数据，可直接覆盖安装；帮助页同步更新了上述说明。
```
