# 秒算虾料 0.3.7 应用市场更新说明（安卓端）

> 用途：应用市场「版本更新内容 / 更新日志」输入框，直接复制下面代码块里的纯文本。
> 简单版给市场默认展示用，详细版留给要求「详细更新内容」的市场。
> 本版没有改计算规则，只是录入手感与界面位置的问题修复，数据全部保留。

---

## 一、简单版（约 210 字，推荐直接用这版）

```
0.3.7 更新：录入更顺手

1. 键盘上的「下一步」会沿本行一格一格往后走；格子跑出屏幕时表格自动滚过去，输入框始终看得见。
2. 本行最后一个可填格填完，再按「下一步」直接跳到下一行的棚号；「下一行 ▾」遇到下一行这格不能填时，也会落到下一行第一个能填的格，不再按了没反应。
3. 「重置」按钮固定在右下角，表格左右上下怎么滚都在原位，随时点得到。
4. 棚号列加宽、字号加大并固定，不随手机字体大小变化；一行棚号最多 99 个，超出即时提示。
```

## 二、详细版（约 490 字）

```
0.3.7 更新说明

【录入更快】
· 键盘上的「下一步」沿着本行可填的格子一格格往后走，格子被挤出屏幕时表格自动滚过去，输入框始终看得见，不会出现「按了没反应、其实是在屏幕外」。
· 本行最后一个可填格填完再按「下一步」，直接跳到下一行的棚号，接着往下录，不用来回点。
· 「下一行 ▾」修好了：下一行这一格不能填（比如下一行还是空的）时，会自动落到下一行第一个能填的格子，不会再按了原地不动。
· 连续快速点「下一步」不会重复跳格、重复结算，号码不会被算乱。

【棚号看得更清楚】
· 棚号列加宽，字号加大并固定，不跟随手机「字体大小」变化，长号码不再挤成一团。
· 手机档一行 7 个字、最多两行；屏幕更宽（平板、横屏）时一行 9 个字，「1-40」这类区号不会从中间切断。
· 一行棚号最多 99 个：超出会弹出提示，超出部分不计入棚数和料量；改回合法值后自动接着算。

【「重置」随时点得到】
· 右下角「重置」固定在原位，表格左右滚动、上下滚动都不影响，滑到最右边的列也不用再滑回来找它。
· 点它仍然先弹确认框，不会误触到底下的格子。

【其它】
· 帮助页同步更新了上述说明（中文 / 英文）。
· 升级不会清空已保存的数据，可直接覆盖安装。
```
