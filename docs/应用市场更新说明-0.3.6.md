# 秒算虾料 0.3.6 应用市场更新说明

> 适用版本：Android 0.3.6（versionCode 9）
> 对比版本：0.3.5
> 用途：应用市场"版本更新说明/更新日志"可直接复制下方文案。

## 一、短版（约 60 字，适合更新弹窗）

棚号改成一本账：每行填的号只在没被下面行认领时才算料，被占走的号会自动退回；棚号气泡可选中转出、转入、删除；空行自动回收、下面的行自动上顶。

## 二、标准版（约 180 字，适合应用市场更新说明）

这次重做了棚号的计算和录入，改完更不容易算错：

1. 每行棚号改为"后填的覆盖先填的"，棚数只认这个结果，不再有"第一行当总棚数"。
2. 棚号分"你填的原文"和"实际拥有的号"两层：被下面行占走的号只是暂时不算，下面改小或清空会自动退回来，不会永久消失。
3. 点"棚数"弹出的棚号气泡可以选中号码：转出、转入到别的行，或者删除（确认框会说清是退回上面还是真的不再算）。
4. 被覆盖成 0 棚的行，离开编辑后自动回收，下面行上顶、底部补空行，表中间不留洞。
5. 棚号格两行极简显示，字号固定不缩放、不裁剪。

升级不清空数据；签名与 0.3.5 一致，可直接覆盖安装。

## 三、详细版（适合应用商店"更新内容"长文本）

本次 0.3.6 集中重构"棚号 → 棚数 → 料量"这条链路：

- **所有行平等**：取消"第一行 = 总棚数"。每行的有效棚数 = 本行棚号在"后行优先"覆盖后实际占有的号码个数。改棚号等于改棚数，平均吃料保持不变，料量按"平均 × 新棚数"重算；别的行覆盖导致棚数变化也照此处理。
- **声明与显示分开**：每行落盘的是你填的**原文**，显示的是打点覆盖后**实际拥有**的号。第 1 行填 `1-40`、第 2 行填 `1-15`，第 1 行显示 `16-40`、按 25 个棚算料；把第 2 行改成 `1-5`，第 1 行变成 `6-40`；清空第 2 行，第 1 行回到 `1-40`。被占走的号随时能退回，不会像以前那样一旦被占就永久消失。
- **边输入边全表重算**：棚号格每敲一个字符，全表的归属、棚数、料量、水量、称料一起刷新。输入过程用"进入编辑前的快照"重推，`16-40` 打到一半的 `16-4` 不会把别人的 `4-15` 永久抢走；正在编辑的那一行永远显示你敲的原文。
- **棚号气泡：选中 / 转出 / 转入 / 删除**：点号码即选中（绿底转蓝底）。⋮ 菜单提供全选、反选；选中后可删除或转出。转出只把号码记进内存待转池、来源行一个字不动，点开另一行的气泡才能"转入"，任何其它点击都会作废。转入按号码集合换主人，两行文本重排成实际拥有的号；把整行号转给一个空行会被拦下（那只是把整行往下挪一格）。
- **删除说清去向**：删除只从本行声明里剔除。上面还有行填过这个号 → 会退回那行继续算料；没有任何来路 → 才是真删除。确认框分三种说法，并把"真删的号"点名列出（过长只列前 12 个并注明总数）。
- **空行自动回收**：填过内容但有效棚数为 0 的行，在换格收起、切批次、退出、载入这些结算时刻整行销毁，下面的行自动上顶、底部补一行空行保持总行数；一次结算把所有该删的行一起删完，不会"按一下键盘进一行"。编辑途中只把料列置灰、不动数据。正在编辑的格子会跟着行号平移，自己那行被删时浮层直接收起，绝不把字提交错行。
- **棚号格显示**：每行不超过 9 个字符、最多两行，连续区间绝不从中间切断；不丢信息就不出现省略号，必须截断时优先露出首尾两个关键区间。字号固定 16dp，不随内容自适应、也不跟随系统字体大小；棚号列已加宽，两行折叠结果不会被裁边。
- **首次填棚号**给一次格式提示（`1-40`，最大 1000），可直接跳到帮助页；点"棚数"弹出的气泡左边缘对齐棚数格，号码太多时在弹窗内滚动。

升级不会清空已保存的数据。与 0.3.5 签名一致，可直接覆盖安装；若设备上装的是其它密钥签的包，需要先卸载（会清数据）。
