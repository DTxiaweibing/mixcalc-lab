# 秒算虾料 0.3.4 应用市场更新说明

> 适用版本：Android 0.3.4（versionCode 7）
> 对比版本：0.3.3
> 用途：应用市场“版本更新说明/更新日志”可直接复制下方文案。

## 一、短版（约 60 字，适合更新弹窗）

新增「下一行」快捷录入、棚号输入校验和顺序提醒；隐藏列后自动铺满；滑动更顺，录入更省心。

## 二、标准版（约 180 字，适合应用市场更新说明）

这次主要让日常录入更顺手，也更不容易点错：

1. 新增「下一行」按钮：键盘弹出时出现在右下角，点一下就能接着填同一列的下一行；键盘收起后自动隐藏。
2. 棚号输入更规范：只接受数字和常用分隔符，字母、汉字、表情不会误输入。
3. 增加了录入顺序提醒：前面还有空行时，会提示先填哪一行，避免漏行、跳行。
4. 第一次填第一行棚号时，会提示填写格式（如 1-40），也可以点“查看帮助”。
5. 第一行必须先填棚号，再填棚数，避免计算不准。
6. 隐藏部分列后，剩下的列会自动放大铺满屏幕，不再右侧留白。
7. 滑动更跟手：快速滑动或猛甩时也能滑到位，不会中途停住。

升级不会清空已保存的数据；首次打开新版本时，可能需要重新确认隐私政策与用户协议。

## 三、详细版（适合应用商店“更新内容”长文本）

本次 0.3.4 版本围绕“录入更快、更不容易出错”做了一轮优化：

- **新增「下一行」快捷按钮**：用键盘录入时，右下角会出现「下一行 ▾」，点一下直接跳到同一列的下一行，不用再手动找格子；键盘收起后按钮自动隐藏，不占地方。
- **棚号输入更规范**：棚号格只接受数字和常用分隔符（如 1-40、1到40、1、2、3），字母、汉字、表情等不会误输入，减少录错。
- **录入顺序有提醒**：如果前面还有空行，直接点后面的空行会提示“请按顺序录入”，并指出应该先填哪一行；已经填过数据的行不受影响。
- **第一行棚号有格式提示**：第一次填第一行棚号时，会提示“最小-最大，如 1-40”，也可以点“查看帮助”看详细说明。
- **第一行先填棚号再填棚数**：避免只填棚数、没填棚号导致计算不对。
- **隐藏列后自动铺满**：用列操作隐藏部分列后，剩余列会自动放大铺满屏幕，不再出现右侧空白。
- **滑动更顺**：调整了表格惯性滑动，快速滑动、猛甩时也能滑到位，不会中途停住。

升级不会清空已保存的数据。首次打开新版本时，可能需要重新确认隐私政策与用户协议；建议升级前把重要数据截图或抄录一份。
